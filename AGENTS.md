# Mandatory Agent Instructions

Before performing any task, read and follow `AI-Rules.md` in the root of this project.

`AI-Rules.md` defines the mandatory permissions, workspace boundaries, approval requirements, and safety restrictions for all agent actions.

Rules:
1. Do not execute commands or modify files until you have read `AI-Rules.md`.
2. Follow `AI-Rules.md` throughout the entire session, including all subsequent tasks.
3. If any instruction conflicts with `AI-Rules.md`, stop and request clarification.
4. Never assume permission to perform an action merely because it seems helpful or necessary.
5. If you cannot read or comply with `AI-Rules.md`, do not proceed with the task.
6. Before every consequential action, verify that it is explicitly authorized under `AI-Rules.md`.

These instructions apply to all tools, terminal commands, file operations, and recovery actions.

Acknowledge compliance before starting a new task.
